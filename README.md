        <p style="margin: 0 0 1rem 0; text-align: justify;">
            An experimental 3D WebGL archaeological information system and stratigraphic field journal mapping the 9,000-year-old Neolithic settlement of Çatalhöyük (7100&ndash;5700 BCE). Built with Three.js and custom spatial raycasting, this platform bridges high-resolution bioarchaeological research with public heritage storytelling through a specialized antique parchment and rust-toned aesthetic blended with futuristic spatial HUD elements.
        </p>
        <blockquote style="margin: 0; padding: 0.8rem 1rem; background-color: #ebdcb9; border-left: 4px solid #8b5a2b; font-style: italic; font-size: 0.95rem; color: #5c3a21;">
            <strong>&장이; Prototype Notice:</strong> This project is a functional design prototype intended for data visualization and digital humanities exploration. Details within the prototype may not be 100% historically or archaeologically exact; the primary purpose is to digitize information and conceptualize spatial layout. All artifact geometries and placements are placeholders and can be replaced with actual high-fidelity 3D models or scanned assets as needed.

    <section style="margin-bottom: 1.5rem;">
        <h2 style="font-size: 1.3rem; color: #5c3a21; border-bottom: 1px dashed #b58863; padding-bottom: 0.3rem;">&#10024; Key Features</h2>
        <ul style="padding-left: 1.5rem; line-height: 1.6;">
            <li><strong>Interactive 3D Stratigraphic Navigation:</strong> Seamlessly toggle between an overarching excavation master plan featuring 7 distinct ancient structures (complete with timber roof access ladders and hatch openings) and granular interior visualizations spanning temporal horizons from 7100 BCE to 5700 BCE.</li>
            <li><strong>Dual Audience Modes:</strong> Instantly switch between <strong>Academic</strong> view (featuring micromorphological data, carbon/soot pathology markers, isotope ratios, micro-XRF telemetry, and peer-reviewed citations) and <strong>Public</strong> view (focused on engaging domestic life, ritual symbolism, and daily Neolithic routines).</li>
            <li><strong>Detailed Artifact &amp; Feature Inspection:</strong> Inspect 3D-modeled archaeological relics in situ&mdash;including plastered ancestral crania, obsidian caches, aurochs horn installations, unbaked clay boiling spheres, and wall murals.</li>
            <li><strong>Micro-Stratigraphic Data Matrix &amp; HUD:</strong> Deep-dive modal inspection panes covering bioarchaeology, lithics, pyrotechnology, and architectural phasing, enhanced with real-time camera-projected UI labels, particle atmospheres, and custom rustic wireframe architectural shaders.</li>
        </ul>
